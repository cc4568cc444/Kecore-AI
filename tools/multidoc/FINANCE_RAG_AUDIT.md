# 金融 RAG 修复与验证（2026-09-11）

## 根因与修改

1. 完整表格同时以 Markdown 形式混入文本切片；文本切片可能丢失区域标题、年份和指标名称。数值任务现在拒绝缺少表头的文本表格片段，并使用现有补检索寻找完整表格，避免将区域值当成公司总量。
2. 固定字符窗口可能截断表格。现在优先保留期间/单位表头和完整目标行，减少无关叙述挤占证据预算。
3. `$ 49. 63` 曾解析成 `49`；数值正则现兼容小数点后的 HTML 空白。
4. 模型填写的公司必须与引用证据的公司一致。
5. 模型可能把原文的千误标成百万；两端同时错时百分比仍然正确。现在优先采用原文数值旁和表头的单位，生成上下文使用校验后的数值。模型的 rawValue 仍保留用于审计。
6. 少量召回片段不能证明整个年报未披露指标。回答提示明确限制缺失性断言，避免据此推断停止披露或披露政策变化。
7. 一个任务涵盖多个公司/财年时，原逻辑可能只覆盖其中一个范围。现在证据选择与补检索分别保障各公司/财年，保留原任务 ID 以维持计算依赖。

没有改写标准答案、按题号硬编码答案、扩大已知问题排除名单或重新写入向量索引。
